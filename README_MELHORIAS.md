# Conecta Campus - Versão Melhorada

## Principais melhorias

- Interface redesenhada com identidade visual consistente, cards profissionais, navegação clara e layout responsivo.
- Login e cadastro com melhor contraste, campos acessíveis, rótulos vinculados e navegação por teclado.
- Dashboard funcional em CanvasJS, com gráficos de colunas e rosca usando dados reais do backend.
- Comunicados com listagem melhorada, estado vazio, criação e edição corrigidas.
- Fórum com criação de tópico, visualização, edição e respostas carregadas por tópico.
- Enquetes com visual de votação moderno, criação de enquete com opções e controller de votos.
- Feedback com formulário mais claro e opção de envio anônimo.
- Usuários com listagem melhorada, busca no frontend, edição e ações acessíveis.
- Correções de textos com acentuação quebrada e telas incompletas do Eclipse.

## Validação feita

- Projeto Java recompilado com Tomcat 11 e bibliotecas locais.
- Verificação de páginas vazias, CSS inexistente, textos corrompidos e referências quebradas.

## Observação

O banco de dados não foi alterado. As melhorias usam as tabelas e DAOs já existentes no projeto.
